# Code de conduite

Auspex adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

En résumé : chacun participe dans le respect des autres, quels que soient son
niveau d'expérience, son origine ou son identité. Critiquer le code, jamais
les personnes ; accueillir les questions des débutants ; ne publier aucune
information privée d'autrui, ni aucune donnée réelle d'un réseau (adresses,
noms d'hôtes, captures).

Un comportement inacceptable peut être signalé de façon confidentielle au
mainteneur du projet par le signalement privé de GitHub (onglet **Security →
Report a vulnerability**, en précisant « code de conduite » dans le titre).
Les signalements sont traités avec discrétion ; les mesures vont du simple
rappel à l'exclusion du projet.
